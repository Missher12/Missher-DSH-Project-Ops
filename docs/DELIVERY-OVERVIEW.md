# 标题修复与交付总览（0.4.2 修复分支）

更新进度时不再需要重填标题、需求和方案。创建任务仍要求完整资料；后续更新只传变化的字段和当前修订号，缺省字段保留原值。标题为空、类型不符或超过长度时分别提示原因，旧修订不会被误判为成功。

Project Ops 汇总**当前会话所属工作区**的交付记录：根目录的 `PLAN.md` / `READY.md`，以及 `docs/tasks` 下含任一文档的直接子目录。旧命名目录、普通 Markdown 和只有 READY 的交付都可发现；损坏的 PLAN 不影响读取同目录的 READY。没有文档的历史聊天不会被扫描或自动伪造成交付。

列表支持分批加载和已加载记录检索，不再静默截断为 100 条。每条显示标题、相对位置、来源、交付状态与文档入口；托管 READY 的产物和验收摘要按会话报告展示。点击文档仍使用宿主原生预览。刷新、关闭或切换会话会取消旧读取。

“关联当前方案”不表示验收通过；普通记录、待核对、尚未交付和历史交付保持明确区分。宿主目录接口本身截断时显示提示，插件不能承诺读取宿主没有返回的目录。检索只覆盖已加载内容，完整报告以 READY 原文为准。
