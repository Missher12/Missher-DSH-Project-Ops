## 当前界面（0.4.0，两行任务行）

- `task-panel-0.4.0.jpg`（1280×720）：会话标题栏 **Project Ops** 入口打开后的任务面板，**亮色主题**。
- `plan-preview-0.4.0.jpg`（1280×720）：点击行内“方案”后，PLAN.md 由宿主原生右侧栏预览打开，**深色主题**（与面板截图不是同一主题批次）。

两张图取自 2026-10-17 的隔离合成验收：官方 npm 0.2.1-alpha.5 Web 宿主、独立合成 Profile 与合成工作区、无外部模型调用；同批次还覆盖了 1280×720 与 390×844 两种尺寸的亮/暗主题、窄宽无横向溢出、长标题 tooltip、未生成文档禁用、`Escape` 与点击外部关闭、焦点回到入口、刷新与零控制台错误。配图只说明界面形态，不构成发布、安装或功能验收。

## 命名与图注要求

新增截图使用 `.jpg` 或 `.png`，文件名带上版本，例如 `task-panel-<版本>.jpg`。图注必须写明：版本、界面形态、宿主来源与版本层级、截取方法（隔离合成 Profile、主题、窗口尺寸），并注明配图不代表发布或安装状态。图注与文件名不得包含个人会话、账号、机器绝对路径或凭据。
